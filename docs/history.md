# История решений (октябрь 2026)

1. **Подписка nosok в PassWall**: узел-заглушка «App not supported» → включили Send HWID;
   «Limit of devices reached» → освободили слот устройства у провайдера.
2. **Не всё через VPN**: создали правило MyDirect (группа RU) со списком доменов пользователя
   + `regexp:\.(ru|xn--p1ai|su)$`, узел Split (shunt): MyDirect → напрямую, остальное → nosok.
3. **VK не открывался**: в Basic Settings был выбран не Split, а сразу Финляндия;
   плюс выключили «Direct DNS result write to IPSet».
4. **Удалённый доступ**: WireGuard отвергли (режется в РФ), сделали обратный SSH-туннель
   dbclient → Aeza (пользователь `tunnel` с жёсткими ограничениями), служба procd `fstunnel`.
   Ошибка: служба падала без `HOME=/root`.
5. **router.fspirat.online**: nginx + basic auth + certbot. DNS оказался на Cloudflare.
6. **Страница /router/**: CGI на роутере + nginx-прокси с токеном. Токен сначала в заголовке —
   uhttpd его не пропускает → перешли на cookie.
7. **Автопереключение**: сначала по TCP-пингу; затем добавили настоящую проверку
   через SOCKS 1070 (`http://www.gstatic.com/generate_204`, HTTP вместо HTTPS — меньше
   накладных, ~240 мс). Переключение после 2 провалов подряд, только среди узлов без LTE/Россия/Обход.
8. **Telegram-уведомления** с сервера (cron раз в минуту), а не с роутера — Telegram из РФ блокируют.
9. **fail2ban**: не стартовал из-за отсутствующего лога jail 3x-ipl от 3x-ui.
10. **Тест скорости** через Cloudflare: `/meta` пустой → `/cdn-cgi/trace`; большие файлы не
    отдаются → куски по 25 МБ; прямой тест шёл через VPN → выключили `localhost_proxy`.
11. Страница разбита на вкладки «VPN» / «Роутер и сеть», кнопки управления сверху.
