# Приложение для iPhone. Этап 4: все экраны — отчёт

13.10.2026. Сервер и роутер не трогал: всё новое — код приложения в `ios/`.

## Коротко
- Внизу появилась панель вкладок: **Сводка, VPN, Устройства, Обход, Журнал**; шестерёнка на каждой вкладке открывает полные **Настройки**.
- Оформление — в стиле **Liquid Glass** (iOS 26): стеклянные панель вкладок, кнопки, фильтры и главная карточка экрана. На iOS 17–25 вместо стекла — полупрозрачный материал.
- **Данные в переключателе приложений больше не скрываются.** В Настройках — переключатель «Скрывать в переключателе приложений» (по умолчанию выключен). Face ID при возврате — как настроено.
- Мелочи «Сводки»: цифры без широких пробелов, «9,2 ГБ» с запятой, подпись проверки VPN не переносится.
- Сборка: `Router-5.1.ipa` (запуск 5 `iOS TestFlight`, метка `[ios ipa]`). Ставится так же: подписать своим сертификатом в ESign.

## Экраны
- **VPN** — режим (через VPN / напрямую), серверы по группам с пингом и задержками сервисов, сортировка, «Лучший сервер для YouTube / Discord / …», карточка сервера («Проверить сейчас», «Подключить», «Напрямую, без VPN» — окно и Face ID), подписки с «Обновить», свои серверы NL и DE (только просмотр), тест скорости через VPN и напрямую с историей за 90 дней, история связи за 24 ч / 7 / 30 дней, история переключений.
- **Устройства** — поиск по имени, IP и MAC, фильтры (все, в сети, не в сети, ограничены), «Новые за неделю», группы 5 ГГц / 2,4 ГГц / кабель / не в сети, метки «без интернета», «по расписанию», «мимо VPN». Карточка устройства: сигнал, скорость, трафик за день и месяц, «скрытый MAC», переименовать, выключить и включить интернет, мимо VPN, расписание по времени роутера (Самара).
- **Обход** — zapret (вкл/выкл, способ 1/2/3 с проверкой, что применился, «Проверить YouTube и Discord»), Telegram через Cloudflare (экспериментально), сервисы напрямую, сайты без VPN (MyDirect): свои можно добавить и убрать, общий список — только просмотр.
- **Журнал** — 24 ч / 7 / 30 дней, фильтры «Ошибки / Внимание / Действия», поиск, разбивка «Сегодня / Вчера / 12 октября», уровень — цветом и словом.
- **Настройки** — Face ID, через сколько блокировать, Face ID для опасных действий, «Скрывать в переключателе приложений», устройства с доступом (телефоны и браузеры, «Отозвать»), журнал входов, «Выйти на этом iPhone», «Выйти везде» (окно и Face ID), тема, ссылки, о приложении.

Все опасные действия идут через окно подтверждения с текстом от сервера; самые опасные — ещё и Face ID. Ничего не выполняется свайпом.

## Как проверено
- 185 автотестов внутренней части — на Linux в GitHub (`iOS core tests`).
- Сборка на Mac (Xcode 26.6, iOS SDK 26.5): черновик этапа собрался с первого раза без ошибок и предупреждений; после исправлений собран `.ipa`.
- Четыре независимые проверки кода (безопасность, поведение по спецификации, оформление и доступность, устройство кода) с перепроверкой каждой находки: подтверждено и исправлено 44 замечания (2 важных, 42 мелких), 12 отклонено.
  - Важное: пока приложение заблокировано, открытые окна теперь закрыты и для VoiceOver; повторная попытка чтения данных после сбоя.
  - Плюс: клавиатура убирается при блокировке, токен не уходит при переадресации, проверка ключа `/me` идёт первой и одна.

## Что проверить на iPhone
- Вкладки открываются, данные на каждой есть.
- Переключатель приложений: видна «Сводка», а не значок.
- Безопасное: подсветка, «Проверить сейчас» у одного сервера, тест скорости, «Проверить YouTube и Discord», поиск и фильтры в Устройствах и Журнале, переименование устройства.
- Опасные (перезапуск VPN, смена сервера, выключение интернета устройству, MyDirect, zapret, перезагрузка) — только вместе и с вашего разрешения: они рвут связь на несколько секунд.
- Крупный шрифт и тёмная тема.
- Кнопка закрытия в окнах достаточно крупная (проверить на устройстве).

## Как откатить
- Поставить прошлую сборку `.ipa` (артефакты хранятся 7 дней) или отозвать телефон в веб-панели / `/apps`.
- Рубильник `app_disabled` на сервере выключает приложение для всех (CLAUDE.md, «Приложение iOS»).
