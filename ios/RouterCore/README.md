# RouterCore

Swift-пакет без зависимостей (только Foundation) — «ядро» приложения «Роутер» для iPhone.
В нём нет интерфейса: только то, что можно проверить тестами на Linux.

Что внутри (`Sources/RouterCore`):

- `APIClient.swift` — запросы к `https://fspirat.xyz/router/app/v1/`: ключ только в заголовке
  `Authorization: Bearer …`, без cookie и кэша, таймауты 15/30 с. Без ключа или с испорченным ключом
  запрос не уходит (иначе fail2ban).
- `Endpoints.swift` — все адреса и тела запросов: действия этапов 3 и 4 (`RouterAction`), отзыв доступа
  (`/devices/revoke`, `/devices/revoke-all`).
- `Models.swift`, `Models+Stage4.swift`, `JSONValue.swift` — разбор ответов (`/status`, `/net`, `/led`, `/data`, `/me`,
  вход; этап 4: `/zapret`, `/tgws`, `/mydirect`, `/vds`, `/devices`, ответы действий).
  Разбор «терпеливый»: `null`, число строкой или битый элемент списка не ломают весь ответ.
- `APIError.swift` — коды ошибок и русские тексты для них; когда выходить из аккаунта (только `401 token_*`).
- `LoginFlow.swift` — вход: пароль → число в Telegram-боте → ключ.
- `Actions.swift` — действия (проверка, перезапуск VPN, обновление подписок, перезагрузка, подсветка),
  подтверждение 428, опрос задач `/jobs`, что делать после действия.
- `Summary.swift` — правила «Сводки» (итог, сервер, задержка, сервисы, подписка, роутер, события, график).
- `Aftermath.swift` — что делать после действия этапа 4: «тихое» окно, баннер, тост, повторные чтения, быстрый опрос
  zapret, блокировка кнопок PassWall, проверка «применилось ли», тексты ошибок, локальные изменения состояния.
- `VPN.swift`, `HistoryChart.swift`, `Devices.swift`, `Schedule.swift`, `Bypass.swift`, `Journal.swift`, `Access.swift` —
  правила вкладок VPN, Устройства (и карточка, расписание), Обход (zapret, Telegram, сервисы, MyDirect), Журнал, Настройки
  (доступ, журнал входов, «Скрывать в переключателе приложений»).
- `Format.swift`, `Format+Stage4.swift` — форматирование чисел, скоростей, размеров и времени (время — Самара, UTC+4).
  С этапа 4 — десятичная запятая («9,2 ГБ») и неразрывный пробел перед единицей («64 мс»).
- `Validation.swift`, `Session.swift` — проверки ввода, сроки входа, ссылки для настроек.
- `SampleJSON.swift`, `SampleJSON+Stage4.swift` — образцы ответов из контрактов этапов 3 и 4 (для превью и тестов,
  без настоящих адресов и ключей).

Правила взяты из контрактов этапов 3 и 4 (сервер `server/auth/app.php` и веб `web/app.js`).

## Тесты

Нужен Swift 5.9 или новее (на Linux — `swift test` в `ubuntu-24.04`, на Mac — Xcode 26):

```sh
swift test --package-path ios/RouterCore
```

Тесты не ходят в сеть: ответы сервера подставляются, часы «ненастоящие», поэтому всё проходит за секунды.
