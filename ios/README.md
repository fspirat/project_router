# Приложение «Роутер» для iPhone

Это инструкция для владельца: как поставить и обновить приложение, как отозвать доступ телефона и что делать, если телефон потерян.
В конце есть короткий раздел для разработчика.

> Адреса в примерах ненастоящие (`203.0.113.10`). Пароли, ключи и файлы сертификата не пишите в чат и не кладите в git.

---

## 1. Что это и что умеет

«Роутер» — та же веб-панель `fspirat.xyz/router/`, только в виде приложения для iPhone. Приложение работает с тем же сервером.

- **Внизу пять вкладок:**
  - **Сводка** — всё ли работает, текущий сервер, YouTube / Discord / Telegram, роутер, кнопки «Проверить», «Перезапустить VPN», «Обновить подписки», «Перезагрузить роутер», подсветка.
  - **VPN** — серверы с пингом, смена сервера, «Напрямую, без VPN», подписки, тест скорости, история связи.
  - **Устройства** — кто в сети, переименовать, выключить и включить интернет, «мимо VPN», расписание.
  - **Обход** — zapret, Telegram через Cloudflare, сервисы напрямую, сайты без VPN (MyDirect).
  - **Журнал** — события за 24 ч / 7 / 30 дней, фильтры и поиск.
- **Настройки** — шестерёнка справа вверху на любой вкладке: Face ID, список телефонов и браузеров с доступом, журнал входов, выход, тема, ссылки.
- Данные обновляются сами, пока экран открыт. Свёрнутое приложение к серверу не обращается.

## 2. Как поставить и обновить

Своей подписки Apple у вас нет, поэтому приложение ставится файлом `.ipa`. Вы подписываете его своим сертификатом в ESign.

### Шаг 1. Получить новый файл `.ipa`
Выберите один способ:
- **Проще всего** — написать Claude: «собери ipa». Claude запустит сборку и пришлёт ссылку на запуск.
- **Самому, кнопкой.** GitHub → репозиторий роутера → **Actions** → **iOS TestFlight** → **Run workflow**. Ветка `main`, поставить галочку «Собрать файл .ipa без подписи (для своего сертификата) вместо отправки в TestFlight» → зелёная кнопка **Run workflow**. Галочку «Отправить сборку в TestFlight…» можно не трогать: с галочкой `.ipa` в TestFlight ничего не уходит.
  - Кнопка **Run workflow** появится, только когда файл сборки попадёт в ветку `main` (после слияния PR). До этого — способ ниже или через Claude.
- **Коммитом.** Если в сообщении коммита есть метка `[ios ipa]`, файл соберётся сам, с любой ветки. Условия: коммит меняет что-то в папке `ios/` и он последний в отправке (push).

Сборка обычно занимает несколько минут. Готова, когда у запуска появится зелёная галочка.

### Шаг 2. Скачать файл на iPhone
1. Откройте в Safari страницу запуска сборки (ссылку пришлёт Claude, или Actions → iOS TestFlight → верхний запуск с зелёной галочкой).
2. Войдите в GitHub, если попросит.
3. Внизу страницы, раздел **Artifacts**, нажмите `Router-ipa-…` (например, `Router-ipa-6.1`). Скачается zip-архив.
4. Файл хранится **7 дней**. Потом его нужно собирать заново.

### Шаг 3. Распаковать
1. Откройте приложение **Файлы** → **Загрузки**.
2. Нажмите на zip-архив. Рядом появится файл `Router-….ipa` (например, `Router-6.1.ipa`) или папка с ним.
3. Перенесите файл `.ipa` в отдельную папку в «Файлах» (например, «Роутер»), чтобы не потерять его при чистке «Загрузок». Она пригодится, если сертификат отзовут (раздел 3). В файле нет паролей и ключей.

### Шаг 4. Подписать и поставить
1. Долгое нажатие на файл `.ipa` → **Поделиться** → **ESign** (если ESign нет в первом ряду — пролистайте ряд до «Ещё»).
2. В ESign подпишите файл **своим** сертификатом и установите.
3. При подписи:
   - **не меняйте Bundle ID** — должен остаться `xyz.fspirat.router`;
   - **не меняйте название** приложения;
   - **ничего не добавляйте**: никаких плагинов, твиков, dylib, «инжектов».
4. Ставьте **поверх старой версии**, удалять старую не нужно. Если сертификат тот же, что в прошлый раз, вход сохранится и пароль вводить не придётся.

Важно:
- Подписывайте сами, а не через бота продавца сертификата. Тот, кто подписывает, может встроить свой код и получить доступ к роутеру.
- Если старую версию удалить, а потом поставить новую, приложение попросит войти заново. С тем же сертификатом старый ключ отзовётся сам. С другим сертификатом — отзовите старую запись телефона (раздел 5).
- В «Настройки» → «О приложении» → «Версия» видно, какая сборка стоит.

## 3. Если приложение перестало открываться

Чаще всего это значит, что продавец или Apple **отозвали сертификат**. Роутер, сервер и веб-панель при этом работают как раньше.

Что делать:
1. Купите или получите новый сертификат.
2. Возьмите **тот же** файл `.ipa` (из папки в «Файлах», раздел 2, шаг 3). Пересобирать ничего не нужно.
   - Если файла нет, а 7 дней прошли — получите новый файл (раздел 2, шаг 1).
3. Подпишите его новым сертификатом в ESign и поставьте поверх старого — как в разделе 2, шаг 4.
   - Если iPhone не даёт поставить поверх, удалите старое приложение и поставьте новое. Придётся войти заново.

Что будет со входом:
- Если сертификат от того же разработчика, вход обычно сохраняется.
- Если от другого — приложение, скорее всего, попросит войти заново (пароль и число в боте). Это нормально.
- После нового входа в списке появится ещё один телефон с тем же названием. Старую запись лучше отозвать: «Настройки» → «Доступ к роутеру» → у старой записи кнопка **«Отозвать»**. Если не отозвать, она сама исчезнет через 90 дней.

Пока приложение не открывается, пользуйтесь веб-панелью или ботом.

## 4. Вход и Face ID

### Как проходит вход
1. Введите **«Пароль панели»** (тот же, что в веб-панели) и **«Название телефона»**, например «iPhone 17 Pro». Нажмите **«Войти»**.
2. На экране появится крупное число и надпись «Нажми в Telegram-боте число NN».
3. Бот пришлёт сообщение о входе: три кнопки с числами и кнопка **«Это не я»**.
4. Нажмите в боте **то же число**, что на экране. На это есть 2 минуты.
5. Готово. Приложение предложит включить Face ID.

Пароль на телефоне не сохраняется. Телефон получает свой ключ доступа и хранит его в Keychain — защищённом хранилище iPhone. Ключ не попадает в iCloud и в резервные копии.

Что если:
- **Нажали не то число** — вход отклонится и засчитается как неверный пароль. Начните вход заново.
- **«Это не я»** — нажимайте, только если входите не вы. Вход отклонится, а вход в приложение по паролю **закроется на 1 час для всех**. Бот пришлёт тревогу. Значит, ваш пароль знает кто-то чужой: смените его (раздел 6, шаг 4).

### Сколько действует вход
- Вход продлевается сам, пока вы пользуетесь приложением.
- Он закончится, если **90 дней** не открывать приложение, и в любом случае **через год** после входа.
- За 14 дней до конца года приложение предупредит. Потом просто войдите заново.
- Даты видны в «Настройки» → «Этот телефон»: «Вход до …» и «Не дольше …».

### Настройки защиты («Настройки» → «Защита»)
- **«Face ID при открытии»** — приложение спрашивает Face ID при запуске и после возврата из фона. По умолчанию выключено. Включить можно только после успешного Face ID.
- **«Блокировать»** — когда снова спросить Face ID после возврата: «Сразу», «1 мин» или «5 мин».
- **«Face ID для опасных действий»** — по умолчанию включено. Face ID спрашивается перед «Напрямую, без VPN», перезагрузкой роутера и «Выйти везде». Чтобы выключить это, тоже нужен Face ID.
- **«Скрывать в переключателе приложений»** — по умолчанию выключено: в списке открытых приложений виден последний открытый экран. Если включить, вместо экрана будет значок.

## 5. Как отозвать доступ телефона

Отзыв срабатывает сразу: приложение на том телефоне выйдет и попросит войти заново. Бот пришлёт сообщение.

Отозвать можно в трёх местах:
1. **В приложении** (с любого вашего телефона): шестерёнка → **«Настройки»** → раздел **«Доступ к роутеру»** → у нужного телефона кнопка **«Отозвать»** → ещё раз **«Отозвать»**.
   - У текущего телефона метка «этот телефон» и кнопки нет. Для него — «Выйти на этом iPhone» (ниже).
2. **В веб-панели:** `fspirat.xyz/router/` → вкладка **«Сеть»** → блок **«Безопасность»** → **«Приложения на телефонах»** → **«Отозвать»** → подтвердить.
3. **В боте:** команда **`/apps`** → кнопка **«🔒 Отозвать «название»»**.

Выход из самого приложения («Настройки» → раздел «Выход»):
- **«Выйти на этом iPhone»** — выходит только этот телефон. Ключ стирается, на сервере он тоже отзывается.
- **«Выйти везде — телефоны и браузеры»** — выходят **все** телефоны с приложением, и этот тоже.
  - Галочка **«Также закрыть все сессии веб-панели»** (по умолчанию выключена): выйдут и все браузеры, каждый снова попросит код из Telegram.
  - Дальше: **«Продолжить»** → окно подтверждения → Face ID.

В веб-панели есть кнопка **«Выйти на всех устройствах»** (вкладка «Сеть» → «Безопасность»). Она выходит из панели во всех браузерах, забывает запомненные браузеры **и** выкидывает все телефоны с приложением.

Телефонов с доступом может быть не больше 10. На одиннадцатом вход не пройдёт, пока не отзовёте лишний.

## 6. Если телефон потерян или украден

Делайте по порядку. Первые три шага — сразу, с компьютера или другого телефона.

1. **Отзовите доступ этого телефона.**
   - Бот: `/apps` → **«🔒 Отозвать «название»»**.
   - Или веб-панель: вкладка **«Сеть»** → **«Безопасность»** → **«Приложения на телефонах»** → **«Отозвать»**.
2. **Если на потерянном телефоне был Telegram** — завершите там сеанс Telegram с другого устройства: Telegram → «Настройки» → «Устройства» → потерянный телефон → «Завершить сеанс». Вход в приложение и в веб-панель подтверждается в Telegram, поэтому чужой не должен видеть бота.
3. **Если сомневаетесь, что ещё мог открыть чужой** (например, веб-панель в Safari) — в веб-панели нажмите **«Выйти на всех устройствах»**. Выйдут все браузеры и все телефоны. Потом войдёте заново: пароль и код из Telegram.
4. **Смените пароль панели**, если телефон был разблокирован или пароль где-то записан на нём.
   - Новый пароль не пишите в чат: Claude его видеть не должен. Поэтому пароль меняете вы сами, по SSH на сервере. Если что-то непонятно — попросите Claude подсказать шаги.
   - На сервере (`root@occasional-coffe`) две команды по очереди:
     ```
     htpasswd /etc/nginx/.htpasswd_router bob
     rm -f /var/lib/fspirat-router-auth/password
     ```
     Первая спросит новый пароль два раза. Буквы при вводе не видны — так и должно быть. Вторая удаляет старый сохранённый пароль.
   - Смена пароля сама никого не выкидывает. Поэтому шаги 1 и 3 нужны в любом случае.
5. **Аварийный рубильник** — только если что-то совсем непонятно. Попросите Claude: «выключи приложение рубильником».
   - Это файл `app_disabled` на сервере. Пока он есть, приложение не работает ни на одном телефоне.
   - Веб-панель и бот при этом работают.
   - Рубильник не отзывает ключи. Когда его выключат, телефоны снова заработают. Поэтому сначала шаг 1.
   - Включить приложение обратно — попросить Claude убрать рубильник.

Что может и чего не может вор:
- **Пароля на телефоне нет** — его не узнать из приложения.
- **Ключ доступа лежит только на этом телефоне**, в Keychain. В iCloud и резервные копии он не попадает.
- **Если iPhone заблокирован** кодом или Face ID, вор не откроет и приложение.
- **Если вор знает код-пароль iPhone**, Face ID его не остановит: вместо лица iPhone примет код. Поэтому отзывайте доступ сразу.
- **Если телефон был разблокирован**, а «Face ID при открытии» выключен, вор сможет управлять роутером из приложения, **пока вы не отозвали доступ**. Самые опасные действия (перезагрузка, «Напрямую, без VPN», «Выйти везде») всё равно спросят Face ID, если включено «Face ID для опасных действий».
- После отзыва ключ бесполезен.

Совет на будущее: включите «Face ID при открытии» («Настройки» → «Защита»).

## 7. Если что-то не работает

| Что видите | Что это значит | Что делать |
|---|---|---|
| **«Роутер не на связи»** | Дома пропал интернет или свет, роутер перезагружается или оборвался туннель до сервера. История и журнал видны, кнопки не работают | Подождать 2–3 минуты. Проверить интернет дома. Если не помогло — выключить роутер из розетки на 10 секунд |
| Приложение снова просит **войти** («Доступ этого телефона отозван», «Срок входа истёк», «Ключ не подходит») | Доступ отозвали, или 90 дней не пользовались, или прошёл год | Войти заново: пароль и число в боте |
| **«Повтори через N с»**, «Слишком часто — подожди немного» | Сработал лимит. После перезапуска VPN — пауза 15 секунд для всех телефонов | Подождать столько, сколько написано |
| **«Войти можно через N мин»**, «Вход временно закрыт после неверных попыток» | 5 неверных паролей (в приложении и в вебе вместе) — вход с этого адреса закрыт на 15 минут | Подождать 15 минут |
| Сайт `fspirat.xyz` вообще не открывается с этого адреса | Бан fail2ban на 15 минут: за 10 минут 5 неверных паролей или 10 ошибок приложения (неверный ключ, неверное число или «Это не я» в боте) | Подождать 15 минут или попросить Claude снять бан (нужен ваш IP) |
| **«Telegram-бот недоступен — войти в приложение сейчас нельзя»** | Без бота новый вход невозможен | Подождать, пока бот заработает. Телефоны, которые уже вошли, продолжают работать |
| **«Приложение выключено на сервере. Веб-панель работает.»** | Включён рубильник `app_disabled` | Пользоваться веб-панелью. Включить приложение — попросить Claude убрать рубильник |
| **«Уже 10 телефонов с доступом»** | Лимит 10 телефонов | Отозвать старый (раздел 5) |
| **«Вход отклонён в Telegram»** | В боте нажали не то число или «Это не я» | Начать вход заново. Если «Это не я» — вход по паролю закрыт на 1 час |
| Приложение не открывается совсем | Отозван сертификат | Раздел 3 |

Бан fail2ban закрывает с вашего адреса весь порт 443. С этого адреса на 15 минут перестанут открываться сайты на сервере и свой VPN-сервер NL. Подписка nosok работает.

## 8. Опасные кнопки

Перед опасным действием приложение показывает окно с текстом от сервера: что случится и надолго ли. Ничего не выполняется свайпом, только кнопкой в окне.

**Окно + Face ID** (если включено «Face ID для опасных действий»):
- **«Перезагрузить роутер»** — интернета дома не будет 1–2 минуты.
- **«Напрямую, без VPN»** — весь трафик пойдёт без VPN, автопереключение отключится. Вернуть — выбрать сервер.
- **«Выйти везде»** — выйдут все телефоны (и браузеры, если отмечено).

**Только окно** (VPN перезапускается, связь через VPN пропадает на несколько секунд):
- «Перезапустить VPN»;
- «Обновить подписки» (список серверов качается до 1–2 минут, потом перезапуск VPN);
- «Подключить» другой сервер;
- устройство «мимо VPN» и обратно;
- сайты в MyDirect: добавить и убрать; сервисы напрямую;
- zapret: включить и выключить (перезапуск примерно на 5 секунд).

**Только окно, без перезапуска VPN:**
- **«Выключить интернет»** устройству. Если это этот iPhone в домашнем Wi-Fi, приложение потеряет связь. Вернуть — через мобильный интернет.
- Расписание интернета устройству (убрать расписание — без вопроса).
- Telegram через Cloudflare: включить и выключить.

**Без вопросов:** подсветка, «Проверить сейчас» у одного сервера, тест скорости, «Проверить YouTube и Discord», стратегия zapret 1 / 2 / 3, поиск, переименование устройства, включить интернет обратно. Кнопка «Проверить» на «Сводке» спрашивает только тогда, когда VPN сейчас не проходит: роутер может сам сменить сервер.

## 9. Если появится своя подписка Apple ($99 в год)

Тогда можно ставить приложение через TestFlight: без ESign и без чужих сертификатов, обновления приходят сами.

1. **Шаги в Apple и GitHub** — `docs/ios/plan.md`, раздел 4, пункты 1–4 (около 30 минут, всё в браузере, подойдёт Windows).
   - Ключ App Store Connect API — с ролью **Admin**.
   - В GitHub → Settings → Secrets and variables → Actions — 4 секрета: `ASC_ISSUER_ID`, `ASC_KEY_ID`, `ASC_KEY_P8` (весь текст файла .p8), `APPLE_TEAM_ID`.
   - Файл .p8 и ключи не присылайте в чат.
2. **Слить PR с приложением в `main`.** В TestFlight сборка уходит только из `main`.
3. **Запустить сборку:** Actions → **iOS TestFlight** → **Run workflow**, ветка `main`, галочка «Отправить сборку в TestFlight (иначе только проверка сборки)» включена, галочка `.ipa` выключена.
4. **Через 5–30 минут:** App Store Connect → приложение → **TestFlight** → **Internal Testing** → «+» → создать группу и добавить себя. На iPhone поставить TestFlight из App Store и установить «Роутер».

Сборка TestFlight живёт 90 дней. GitHub сам пересобирает её раз в 2 месяца, а в «Настройки» → «О приложении» появится строка «Сборка действует до …».
После перехода на TestFlight приложение, скорее всего, попросит войти заново. Старую запись телефона отзовите (раздел 5).

### Правила
- **Только `Authorization: Bearer fsr1_…`**, ephemeral `URLSession`, без cookie и без переадресаций. Ключ никогда не в адресе: сервер такой ключ сразу отзывает.
- **В приложении нет секретов**: ни паролей, ни ключа роутера. Пароль не сохраняется. Ключ — в Keychain, `AfterFirstUnlockThisDeviceOnly`. Первая установка (нет `installMarker` в UserDefaults) стирает старый ключ из Keychain и отзывает его на сервере.
- **Подтверждения делает сервер:** опасное действие → `428 confirm_required` (title / text / button / danger) → окно → повтор с `confirm`. Текст окна — от сервера, не свой.
- **Face ID** — перед повтором для `danger == critical` (switch direct, reboot, revoke-all), если включено «Face ID для опасных действий».
- `401 token_*` → выход из приложения; `503 app_disabled` → ключ не трогать.
- **iOS 17+**, Liquid Glass — только под `#available(iOS 26, *)`, на 17–25 — материал. **Swift 5 mode** (`SWIFT_VERSION 5.0`, strict concurrency minimal).
- Тексты, поля API и правила клиента — контракт этапа 3/4. При расхождении прав код сервера.
- Не коммитить `*.p8`, `*.p12`, `*.mobileprovision`, `.xcodeproj`.
